# Documentation

The documentation is split by concern:

- `core-model.md` defines what the base product represents and the rules it enforces.
- `initial-taxonomy.md` lists and explains the one-time broad unassessed starting nodes.
- `architecture.md` describes the runtime, component boundaries, and persistence design.
- `api.md` documents the HTTP interface used by the browser client.
- `agent-api.md` defines the stateless, revision-safe interface intended for AI agents.
- `agent-guide.md` explains project semantics and how an agent should choose, limit, and sequence operations.
- `working_history.md` records notable completed work.
- `todo.md` records unfinished work in the current base scope.

The repository `README.md` is the operating guide. `AGENTS.md` contains mandatory contributor instructions.
